## Sobre o Projeto

Este projeto foi desenvolvido para modernizar o controle de estoque do almoxarifado de materiais utilizados nas aulas práticas do curso técnico de Enfermagem do SENAC Zona Norte.

O sistema permite cadastrar materiais, consultar o estoque disponível, realizar baixas de materiais, excluir itens, pesquisar materiais e visualizar alertas de estoque crítico, utilizando uma API REST para armazenamento dos dados.

---

## Funcionalidades

### Sprint 1

* Cadastro de materiais (POST)
* Listagem de materiais (GET)
* Integração com MockAPI

### Sprint 2

* Validação de retirada de materiais
* Baixa de estoque (PUT)
* Exclusão de materiais (DELETE)
* Bloqueio de retiradas inválidas

### Sprint 3

* Barra de pesquisa de materiais
* Dashboard com total de itens cadastrados
* Destaque visual para estoque crítico (menos de 10 unidades)
* Tratamento de erros com `try/catch`
* Publicação da aplicação no GitHub Pages
