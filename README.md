# Controle de Almoxarifado

## Sobre o Projeto

Este projeto foi desenvolvido para auxiliar no controle de estoque do almoxarifado de materiais utilizados nas aulas práticas do curso técnico de Enfermagem do SENAC Zona Norte.

O sistema permite cadastrar materiais, visualizar o estoque disponível, realizar baixas de materiais e excluir itens cadastrados, utilizando uma API REST para armazenamento dos dados.

---

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* MockAPI
* Git e GitHub

---

## Funcionalidades

### Sprint 1

* Cadastro de materiais (POST)
* Listagem de materiais (GET)

### Sprint 2

* Validação de retirada de materiais
* Baixa de estoque (PUT)
* Exclusão de materiais (DELETE)
* Bloqueio de retiradas inválidas
* Atualização automática da listagem

---

## API Utilizada

Os dados são armazenados utilizando a plataforma MockAPI.

Endpoint utilizado:

https://6a28b1914e1e783349a5e67b.mockapi.io/materiais

## Como Executar o Projeto

1. Clone o repositório:

   ```bash
   git clone <url-do-repositorio>
   ```

2. Abra a pasta do projeto no VS Code.

3. Instale a extensão Live Server.

4. Abra o arquivo `index.html` utilizando o Live Server.

5. O sistema estará pronto para uso.
